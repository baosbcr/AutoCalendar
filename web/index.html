    Then import it into Outlook

    1. In classic Outlook: File > Open & Export > Import/Export.
    2. Choose Import an iCalendar (.ics) or vCalendar file and pick the downloaded file.
    3. Click Import to add the events to your calendar, or Open as New to look them over in a separate calendar first.

    Use the menu rather than double-clicking the file: on some PCs a double-click opens the new Outlook, which gets stuck at a sign-in screen. How the sheet should look, and what you can edit: the guide.
